**Engineering projects**

**[HSED — Hash, Sign, Encrypt, Decrypt](https://github.com/ruwgxo/hsed)**
A Python library and CLI for expressing cryptographic permissions through a four-bit model. Includes policy generation for AWS KMS, HashiCorp Vault, Azure Key Vault, and GCP Cloud KMS.

Start with the [permission model and usage examples](https://github.com/ruwgxo/hsed#the-model), then explore the [tests](https://github.com/ruwgxo/hsed/tree/main/tests) and [integration examples](https://github.com/ruwgxo/hsed/tree/main/examples).

**[Living Threat Intel](https://github.com/ruwgxo/living-threat-intel)**
A threat intelligence pipeline designed around GitHub Actions and version-controlled YAML. Covers collection, deduplication, summary generation, and Sigma/YARA rule generation.

See the [setup and output format](https://github.com/ruwgxo/living-threat-intel#quick-start). Generated rules require review and validation before operational use; AI summaries require an API key and incur API charges.
